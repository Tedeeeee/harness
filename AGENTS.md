# Codex Entry Point

This repository is the personal orchestration harness. Before changing it, read `README.md` and the files under `rules/` that apply to the requested change.

The harness is project-agnostic. Keep project-specific domain rules in the attached project, not here. Keep shared skill instructions in `skills-src/`, then mirror them into `.agents/skills/` and `.claude/skills/` with the repository scripts.

Do not advance a feature orchestration past a meaningful decision without explaining the understanding, impact, alternatives, uncertainty, and requested user decision. Do not claim completion without deterministic verification evidence.
