# Completion and Evidence

Completion is a gate, not a tone of voice. A Feature Run may be marked complete only when the requested scope, applicable rules, changed files, deterministic verification, current project feature document, and remaining uncertainty have been compared.

The completion message must state:

- what behavior is now implemented;
- which project feature document describes it;
- what was verified and how;
- what was not verified;
- remaining risks or follow-up work.

If verification fails, return to the responsible phase. If the result differs from the approved scope, stop and ask whether to revise the scope or implementation. Never hide an unexecuted test, unresolved conflict, stale feature document, or unverified assumption behind a successful-sounding summary.
